# پنل مشتریان OTC روشا

یک پنل مستقل Vue 3 + TypeScript برای خرید و فروش مستقیم رمزارز با صرافی، مدیریت کیف پول، احراز هویت، حساب‌های بانکی، امنیت و پشتیبانی. رابط کاملاً فارسی و RTL است و نسخه موبایل به‌عنوان PWA طراحی شده است.

## اجرا

```bash
npm install
npm run dev
```

حالت نمایشی فقط در development و با `VITE_USE_MOCK_API=true` فعال می‌شود. فایل `.env.development` همین تنظیم را برای اجرای محلی دارد. build انتشار حتی با این متغیر هرگز mock یا عبور از guard ورود را فعال نمی‌کند.

برای ورود نمایشی می‌توان از `09121234567` و هر رمز حداقل ۸ نویسه‌ای استفاده کرد. کد OTP و کد Authenticator در mock برابر `123456` است. درگاه آزمایشی فقط از مسیر داخلی واریز تومان ساخته می‌شود.

## بررسی انتشار

```bash
npm run typecheck
npm run test
npm run build
npm run preview
```

برای اجرای همه کنترل‌های قابل تکرار با یک فرمان از `npm run check` استفاده کنید. تست‌های قرارداد، محاسبات دقیق مالی، اتصال OTP به challenge، یک‌بارمصرف بودن کد و idempotency سفارش و برداشت‌ها را پوشش می‌دهند.

متغیر `VITE_API_BASE_URL` باید به API واقعی اشاره کند. قرارداد live بر احراز هویت با کوکی `Secure`، `HttpOnly` و `SameSite`، محافظت CSRF، OTPهای purpose-bound، estimate/quoteهای نسخه‌دار و کلید `Idempotency-Key` برای عملیات مالی متکی است. هیچ توکن ورود یا proof امنیتی در localStorage ذخیره نمی‌شود.

میزبان‌های مجاز درگاه پرداخت باید به‌صورت نام میزبان دقیق و جداشده با ویرگول در `VITE_PAYMENT_ALLOWED_HOSTS` تنظیم شوند. هدایت production فقط به HTTPS، مبدأ خود برنامه یا یکی از همین میزبان‌ها انجام می‌شود.

فایل‌های `public/_headers` و `public/_redirects` برای میزبان‌های static سازگار با Netlify آماده‌اند؛ در سایر میزبان‌ها همان headerهای امنیتی و fallback تاریخچه SPA باید در لایه CDN یا وب‌سرور اعمال شوند.

## ساختار

- `src/services`: مرز API و backend نمایشی مرکزی
- `src/stores`: وضعیت مشترک احراز هویت، بازار، کیف پول، اعلان و ترجیحات
- `src/utils/financial.ts`: محاسبات decimal مبتنی بر رشته و `BigInt`
- `src/constants`: وضعیت‌ها و نسخه اسناد حقوقی
- `src/components`: اجزای UI، مالی، معامله و کیف پول
- `src/pages`: همه مسیرهای پنل، auth و اسناد حقوقی

فونت IRANYekanX از فایل‌های محلی بارگذاری می‌شود. متن مجوز اصلی بدون تغییر در `public/fonts/FontLicense.txt` نگهداری شده و پیش از انتشار تجاری باید کد مجوز معتبر در محل تعیین‌شده درج شود.
